# Project guidance

## Frontend design
For frontend interface design or implementation, use the project's `frontend-design` skill when available. Also check `ai-workspace/skills/` and parent skill folders for relevant UI skills, and use those that apply. Use the project content, audience, and existing code as design inputs. Review the result at desktop and mobile sizes when a preview is available. Keep keyboard access, visible focus, and reduced-motion support.

## Writing style
Follow the workspace `AGENTS.md`: use ASD Simplified Technical English for all text and documentation.

## Portfolio content and resume
- Before changing portfolio content or data, read `public/assets/Duc-Resume.md` first. Use `public/assets/Duc-Resume.pdf` only if the Markdown file is missing, unreadable, or does not contain the needed information.
- Verify portfolio facts and data against the resume before editing.
- Apply the shared humanizer skill at `../../skills/humanizer/SKILL.md` to portfolio prose during every content or data update. Preserve supported facts, names, and metrics.
