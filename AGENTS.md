# Project guidance

## Frontend design
For frontend interface design or implementation, read and apply `.agents/skills/frontend-design/SKILL.md`. Use the project content, audience, and existing code as design inputs. Review the result at desktop and mobile sizes when a preview is available. Keep keyboard access, visible focus, and reduced-motion support.

The skill comes from [anthropics/skills](https://github.com/anthropics/skills/tree/main/skills/frontend-design). Its Apache 2.0 license is included beside the skill.

## Writing style
Follow the workspace `AGENTS.md`: use ASD Simplified Technical English for all text and documentation.
